# Внутренний курс по машинному обучению

Курс подготовлен на основе [mlcourse.ai](https://github.com/Yorko/mlcourse.ai) (Юрий Кашницкий и соавторы, [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)) для внутреннего обучения в компании.

## Структура

- **`Our/`** — ноутбуки курса. Для каждой пройденной темы: `theory` (теория с разобранными примерами), `practice`/`practice_solution` (задачи для самостоятельной работы и решения), `advanced` (доп. материалы вне занятия). Черновики и более ранние версии — в `Our/_legacy/`.
- **`data/`** — датасеты, на которые ссылаются ноутбуки (пути вида `../data/...`).

## Программа занятий

1. Pandas: анализ данных
2. Визуальный анализ данных
3. Деревья решений и метод ближайших соседей
4. Линейные модели
5. Ансамблевые методы и случайный лес
6. Конструирование и отбор признаков
7. Обучение без учителя
8. Градиентный бустинг

Подробнее — `Our/programma_kursa.docx`.
